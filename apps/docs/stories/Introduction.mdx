# Maru UI

React + TypeScript 디자인 시스템입니다. 컴포넌트 수보다 **접근성, 테스트, 문서, 릴리스의 완성도**에 집중합니다.

## 시작하기

패키지를 설치합니다.

```bash
pnpm add @ohseungik/maru-ui @ohseungik/maru-tokens
```

앱 진입점에서 토큰과 컴포넌트 스타일을 한 번만 불러옵니다.

```tsx
import '@ohseungik/maru-tokens/css';
import '@ohseungik/maru-ui/styles.css';
```

그다음 컴포넌트를 사용합니다.

```tsx
import { Button, Stack } from '@ohseungik/maru-ui';

export function Example() {
  return (
    <Stack direction="horizontal" gap={3}>
      <Button>저장</Button>
      <Button variant="secondary">취소</Button>
    </Stack>
  );
}
```

## 테마

라이트와 다크 테마를 지원합니다. 기본적으로 OS 설정을 따르고, 루트 요소에 `data-theme` 속성을 지정하면 직접 고정할 수 있습니다.

```html
<html data-theme="dark"></html>
```

이 문서 상단 툴바의 **Theme** 메뉴로 두 테마를 전환해 볼 수 있습니다.

## 설계 원칙

- **접근성이 기본값입니다.** 키보드 조작, 포커스 표시, 대비율을 컴포넌트와 토큰 단계에서 테스트합니다.
- **런타임 비용이 없습니다.** CSS 변수와 CSS Modules만 사용하며, 스타일을 만드는 JS가 번들에 들어가지 않습니다.
- **토큰은 3단 구조입니다.** Palette, Scale, Semantic으로 나누고, 테마는 Semantic 단계에서만 바꿉니다.
- **판단 근거를 기록합니다.** 주요 결정은 저장소의 `docs/adr` 폴더에 남깁니다.

## 둘러보기

- **Foundations / Tokens**: 색상, 간격, 타이포그래피 토큰
- **Components**: Button, Text, Heading, Stack. 스토리 화면 하단의 Accessibility 패널에서 axe 검사 결과를 볼 수 있습니다.
