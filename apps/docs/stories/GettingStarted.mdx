# 시작하기

설치부터 첫 화면까지 5분이면 충분합니다.

## 요구사항

- **React 18 이상** (`peerDependencies`). React 19에서 개발하고 테스트합니다.
- **최신 브라우저.** Dialog는 네이티브 `<dialog>`, Tooltip은 Popover API를 사용합니다. Popover API가 없는 브라우저에서는 Tooltip이 최상위 레이어 없이 일반 요소로 표시됩니다.
- 번들러는 ESM과 CSS 파일 import를 지원하면 무엇이든 괜찮습니다. (Vite, Next.js, webpack 등)

## 설치

```bash
pnpm add @ohseungik/maru-ui @ohseungik/maru-tokens
```

`maru-tokens`는 색상, 간격, 글꼴 같은 디자인 토큰(CSS 변수)이고, `maru-ui`가 그 변수를 쓰는 컴포넌트입니다. 컴포넌트 스타일이 토큰 변수를 참조하므로 **둘 다 필요합니다.**

## 스타일 불러오기

앱 진입점에서 한 번만 불러옵니다. 순서는 토큰이 먼저입니다.

```tsx
import '@ohseungik/maru-tokens/css';
import '@ohseungik/maru-ui/styles.css';
```

본문에도 토큰을 쓰면 일관된 모습이 됩니다.

```css
body {
  background: var(--maru-color-bg-default);
  color: var(--maru-color-text-default);
  font-family: var(--maru-font-family-sans);
}
```

## 첫 화면

```tsx
import { Button, Stack } from '@ohseungik/maru-ui';

export function Example() {
  return (
    <Stack direction="horizontal" gap={3}>
      <Button>저장</Button>
      <Button variant="secondary">취소</Button>
    </Stack>
  );
}
```

## 폼 만들기

`Field`가 라벨, 설명, 에러 메시지를 입력 요소와 연결합니다. `htmlFor`, `id`, `aria-describedby`를 직접 맞출 필요가 없습니다.

```tsx
import { Field, Input } from '@ohseungik/maru-ui';

<Field label="이메일" description="로그인에 사용합니다." error={error} required>
  <Input type="email" name="email" />
</Field>;
```

`Select`도 같은 방식으로 `Field` 안에서 라벨과 에러를 이어받습니다. `Field` 없이 쓸 때는 `aria-label`로 이름을 직접 붙여 주세요.

## 테마

라이트와 다크 테마를 지원합니다. 기본적으로 OS 설정을 따르고, 루트 요소에 `data-theme`를 지정하면 고정할 수 있습니다.

```html
<html data-theme="dark"></html>
```

사용자가 고르게 하려면 속성만 바꾸면 됩니다.

```ts
document.documentElement.dataset.theme = 'dark';
```

테마는 Semantic 토큰 단계에서만 바뀌므로, 컴포넌트를 수정할 필요가 없습니다. 이 문서 상단 툴바의 **Theme** 메뉴로 직접 전환해 볼 수 있습니다.

## Next.js (App Router)

빌드 결과물 맨 앞에 `"use client"`가 들어 있어서 Server Component에서 바로 import 할 수 있습니다. 스타일은 루트 레이아웃에서 한 번 불러옵니다.

```tsx
// app/layout.tsx
import '@ohseungik/maru-tokens/css';
import '@ohseungik/maru-ui/styles.css';
```

서버 렌더링에서 쓰는 id는 `useId`로만 만들기 때문에 하이드레이션 불일치가 생기지 않습니다. 자세한 배경은 저장소의 `docs/adr/004-ssr-strategy.md`에 있습니다.

## 자주 겪는 문제

- **스타일이 하나도 안 보입니다.** `styles.css`를 불러왔는지 확인하세요. 컴포넌트가 JS로 스타일을 주입하지 않습니다.
- **색이 적용되지 않고 브라우저 기본 모양으로 보입니다.** `@ohseungik/maru-tokens/css`를 불러오지 않았을 때 생깁니다.
- **다크 모드가 OS를 따라가지 않습니다.** 루트 요소에 `data-theme="light"`가 고정되어 있는지 확인하세요.
- **아이콘만 있는 버튼을 axe가 "이름이 없다"고 지적합니다.** `aria-label`을 붙이세요. Tooltip은 이름을 대신하지 않습니다. ([접근성 원칙](?path=/docs/accessibility--docs) 참고)
